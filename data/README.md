# Data directory

this data is used by the scripts in the scripts directory

## pairs

- Contains the .pairs files generated by pairtools from the wf_PORE-C EPI2ME pipeline (not uploaded)

## contact maps

- Contact maps at 1Mb, 500kb, 250kb and 100kb resolution, generated by cooler cload from the .pairs files.

## matrices

- Matrices in HDF5 format generated by FAN-C

## regions 

- Reference files and results from the HiCcompare package, in bed or bedpe format
